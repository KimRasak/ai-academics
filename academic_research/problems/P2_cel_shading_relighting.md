# 深度档案 `Anime-P2`：为什么打光和视频模型总把 2D 二次元人物变成“油腻 3D 塑料手办”？

> **定位**：SIGGRAPH / CVPR / ICCV（图形学美学 + 扩散重打光/视频生成）
> **一句话初心**：真实摄影的光影服从 3D 物理曲面反射，而 2D 动画的光影本质是**平面图形设计（硬色阶色块 + 刻意抹平鼻梁的人脸法线）**；当现代打光与视频模型把 3D 物理先验硬套在 2D 角色上时，画风瞬间塑料化崩溃。

---

## 1. 为什么非二次元审稿人也会觉得这是个真问题？

不要把这道题讲成“帮画师修二次元图”的垂直工具，而是讲成**生成模型里「物理先验（Photorealistic Prior）」与「非真实感视觉文法（NPR Grammar）」的正面冲突**：

- 在真实摄影里，阴影是 3D 几何法线与光线点积的连续物理结果——鼻梁下有暗影、脸颊有球面明暗过渡、皮肤有粗糙度高光。
- 在专业 2D 动画与顶级三渲二（《罪恶装备》《原神》等 SIGGRAPH 美术分享）里，**物理上完全正确的 3D 人脸阴影反而极度恐怖和丑陋**（鼻影切碎五官、灰暗脏污、塑料球质感）。因此画师和 TA 演化出了三套反物理核心法则：
  1. **抹平人脸法线（Stylized Face Normals）**：把人脸局部法线近似掰平为平滑柱面/球面，刻意消除鼻翼、眼窝、法令纹处的细碎阴影；
  2. **硬切图形阴影与色相偏移（Graphic Cel Bands + Hue Shift）**：明暗边界锐利干净，暗部不是简单乘以灰色（那样会把蓝发/粉肤弄成脏灰绿），而是整体向冷色或暖色做色相偏移；
  3. **黑色线稿与边缘逆光独立于光照物理**：轮廓线不能随强光溶解，轮廓逆光（Rim Light）是干净的平面亮带而非 3D 菲涅尔模糊。

## 3. 经过严酷 SIGGRAPH/CVPR 审稿人二号压测后的 4 条致命防坑与升级方案

> **模拟 AC 压测警示（2026.11.25）**：原设计若只做“拿 `Flat2D → MToon` 训 LoRA 打零样本 `IC-Light`，再顺带做视频”，会被直接拒稿（估分仅 4.0–4.5/10）。必须做以下 **4 项极简却致命的升级**，才能把录用把握拉升到 **7.0–7.5/10（CVPR/ICCV 65–75%，SIGGRAPH 55–65%）**：

1. **必须训「真重打光（Pre-Lit $\to$ Relit）」，绝不能只训「平涂自动加阴影（Flat2D $\to$ Lit）」**：
   - 真实人类画师的 2D 立绘**本来就自带原画阴影和刘海投影**！只从无阴影 `L3_Flat2D` 训出来的模型不会“去原光（De-lighting）”，一上真实手绘图就会叠出极其难看的**双层重影（Double Shadows）**。
   - **极简修法**：输入随机采样同一姿态的 `预打光图（MToon/PBR/其他方向光）+ Flat2D`，目标是目标光源 `L2_Cel_AnimeNormal`，天生学会去光 + 重打光！
2. **正视并超越「10 行免训练强基线」，抓住真正的科学护城河**：
   - 审稿人二号会提出一个比“直接量化 `IC-Light`”强得多的 10 行免训练基线：`IC-Light` 提亮度比值图 $\to$ 在人脸区域做大核双边滤波抹平鼻影 $\to$ 硬阈值化 + 色相暗部叠回原图（保 100% 线稿）。
   - **这条 10 行强基线在 2 个核心地方依然彻底失败（这就是本论文的真护城河！）**：① 平滑人脸亮度比值会**把刘海投在额头上的锐利投影一起糊掉**；② 直接叠回带原画阴影的真实立绘必出**双层重影**！
3. **拒绝把模型训成“VRoid 塑料风格覆写机”：用“内在阴影层 + 渲染域随机化 + 连续法线展平滑块 $\alpha \in [0,1]$”**：
   - 直接做 RGB LoRA 会把 50 个低多边形 VRoid 的画风焊死进输出，毁掉原画师的水彩/粗线/手绘笔触！
   - **极简升级（零公式堆砌）**：① 训练时在 Blender 里做 **Shader 域随机化**（随机线宽、水彩/厚涂/网点底纹），预测**风格无关的内在去光底图 + 硬边阴影掩码 + 逆光掩码**，100% 保住任意手绘画风；② 利用已有的 `L2_Cel_RealNormal`（$\alpha=0$）与 `L2_Cel_AnimeNormal`（$\alpha=1$）成对真值，引入**单个连续标量滑块 $\alpha \in [0,1]$**——**同一张图从 3D 物理鼻影丝滑过渡到 2D 动画干净平面阴影，同时完好保留刘海锐利投影**！这是免训练平滑和普通 LoRA 都绝对做不到的 SIGGRAPH 级招牌卖点！
4. **砍掉强行外挂的视频扩展 + 补齐 3 个公平强基线**：
   - 单兵 4 个月**专注把静态 2D 角色重打光做到封神**（硬边阴影视频闪烁极难修，弱视频反而拉垮整篇论文）；
   - 必须正面对比 **3 个公平基线**：① 10 行免训练人脸平滑比值基线；② `IC-Light` + 动漫底座/Lineart ControlNet；③ **同数据直接 RGB LoRA 微调**（证明我们的内在层/域随机化方案不会把真实手绘图毁成 VRoid 廉价感）；真实手绘盲测集扩充至 **80–100 张跨 ≥4 种画风的合规开源插画**。
