## 一、 核心候选问题总览（白板精选 6+2 个真问题）

### A. 二次元人物专属前沿（现有模型过度偏向真人，空白最大）

#### 1. `A2` — 有限动画作画节奏（一拍二 / 定格-骤变）vs. 连续流匹配 & 3D-VAE 低通冲突
- **想研究的科学问题**：为什么 `Wan2.1/2.2`、`LTX-2` 等现代视频 DiT 在生成二次元动态立绘时，总带着挥之不去的**“均速浮夸插帧味 / 果冻感（AI floatiness）”**，缺乏日漫标志性的“蓄力—骤动—干净定格（hold-and-snap / 一拍二）”节奏？
  - 根因与现代视频基座的三个底层假设正面冲突：
    1. **4× 因果 3D-VAE** 充当时间低通滤波器，会把干净的 2–3 帧定格与 1 帧爆发/涂抹帧（smear/impact frame）糊成重影；
    2. **连续流匹配（Flow Matching）** 在 24fps 真人视频上学会了近匀速平滑轨迹，抹平了动画的非线性节奏与缓入缓出（slow-in/slow-out）；
    3. 现有光流平滑度与 VLM 评分把“定格”误判为卡顿/无动态，把“骤变/残影”误判为闪烁伪影。
- **学术界最新进展（截至 2026.11）**：
  - `AnimationBench`（`arXiv:2604.15299`，2026.04，HKUST/NTU）把迪士尼动画 12 法则量化为 19 维评测，**刚实证了当前所有开源/闭源 SOTA 视频 DiT 在动画节奏、蓄力与停顿上全面拉胯**；
  - 腾讯混元 `AniMatrix`（`arXiv:2605.03652`，2026.05，“*An Anime Video Generation Model that Thinks in Art, Not Physics*”）靠海量私有番剧数据做出了夸张形变与残影，但**未解决可控作画节奏（一拍一/二/三、律表 X-sheet 停顿）与 3D-VAE 时间涂抹的底层矛盾**；
  - 目前唯一直接碰“一拍二”的只有 2026.08 一篇非学术开源博客（*Animating on Twos*, Alvdansen Labs）。
- **真正空白与顶会匹配**：**SIGGRAPH / CVPR / NeurIPS 几乎全空白（潜力 9.5/10）**；视觉对比极直观，数学与架构矛盾干净。

#### 2. `A4` — 通用视频 Reward Model 的“写实主义 & 连续帧偏置”诱发二次元 RLHF 偷偷 3D 化漂移
- **想研究的科学问题**：主流视频 RLHF（`Flow-GRPO`、`DanceGRPO`）使用的通用视频 RM（`VideoReward`、`VisionReward`、`VideoScore2`、`UnifiedReward`、`HPSv3`、`EmoReward`）训练语料几乎全是写实真人/3D CGI。当把它们用于 **2D 二次元角色**时，是否会系统性惩罚**平涂赛璐璐硬阴影**和**一拍二低帧率节奏**，并在在线 GRPO 中把 2D 纸片人偷偷训成**“油腻 2.5D/3D 写实塑料脸（3D-ification）”**？
- **学术界最新进展（截至 2026.11）**：
  - B站/复旦预印本 `AnimeReward / GAPO`（`arXiv:2504.10044`，2025.04）收集 3 万条番剧偏好做了离线 DPO，指出通用 RM 不懂动漫；`AnimationBench`（`2604.15299`）指出通用基准偏向写实；
  - **真正空白（潜力 8.5/10，NeurIPS / ICLR / CVPR）**：至今**没有任何顶会论文用严格受控的反事实实验**（同一角色、同一动作，用 CC0 `VRoid` + Blender 精确渲染“2D 平涂赛璐璐 vs 3D PBR 写实光影”与“12fps 一拍二 vs 24fps 连续插帧”）系统审计主流 Video RM 的写实/帧率偏置，并量化与修复在线 GRPO 的风格漂移坍缩。

#### 3. `A3` — 开放集、表情不变的二次元细粒度部件视觉 ID（`ArcFace` 与 `DINOv2` 的双盲区）
- **想研究的科学问题**：真人 ID 靠骨相（`ArcFace`），但二次元角色共用高度趋同的标准脸模，真正决定“是不是同一个角色”的是**瞳孔高光形状、虹膜配色、刘海分缝/呆毛轮廓、发饰、平涂色板**。`ArcFace` 在二次元上检测和识别双崩，`DINOv2` 对换瞳孔高光/丢发卡视而不见；且 `Identity-GRPO`（`arXiv:2510.14256`）证实直接加 ID 奖励会把脸冻成“贴图僵尸”。
- **学术界最新进展（截至 2026.11）**：
  - `AnimeShooter`（`2506.03126`）、`EntityBench`（`2605.15199`）、`AnimationBench`（`2604.15299`）仍退回用 `SAM + DINOv2 / VLM-Judge` 粗略测角色一致；
  - **关键信号**：2026.10 音频论文 **`KyaraBench & KyaraEmbed`（`arXiv:2610.06013`）** 在声音侧论证“二次元角色身份 $\neq$ 说话人身份”，并**明确指出视觉侧至今缺少对应的开放集二次元细粒度 ID 编码器与评测基准**！
- **真正空白与顶会匹配**：**CVPR / ICCV / NeurIPS（潜力 8.5/10）**，适合做成“细粒度部件 ID 编码器/基准 + 不冻表情的部件解耦对齐”双贡献。

### B. 动态立绘通用前沿（真人与二次元均成立）

#### 4. `P2` — 视频 DiT 与情绪 RLHF 的“情绪强度双峰死区（夸张演戏偏置）”
- **想研究的科学问题**：让视频 DiT 或情绪对齐 RL 模型表现**克制、细腻的 10%–40% 微表情**（“似笑非笑的一丝嘴角上扬”、“微不可察的犹豫”）时，输出往往掉入**双峰死区**——要么 **0% 僵着不动**，要么直接跳到 **100% 舞台剧式夸张大笑/狰狞**。
  - 双重根因：① **CFG 原型相变**：低强度微表情落在无条件“中性脸”的高密度重叠区内，CFG 放大条件/无条件密度比时，会把样本直接推离重叠区、跳向高区分度的夸张原型；② **情绪 RM 的可判别性 Goodhart 偏置**：VLM 裁判与表情分类器（含 `EmoReward`）只给“一眼看得出来”的夸张表情打高分。
- **学术界最新进展（截至 2026.11）**：
  - 语音驱动显式参数路线较拥挤（`AUHead 2602.09534`、`GemTalk 2608.00663`）；通用视频 DiT 刚出现 `EmoWorld`（`2608.06231`，免训练情绪轨迹引导）与 `EmoReward`（`2611.06518`，情绪 GRPO）；
  - **真正空白（潜力 8.5/10，NeurIPS / CVPR）**：无人诊断或解决文本驱动视频 DiT 与情绪 RLHF 中由 CFG + 可判别性奖励共同造成的“细腻微表情双峰死区”。

#### 5. `P1` — 潜空间视频 DiT 的“眼神直视断裂与前庭眼反射（VOR）缺失”
- **想研究的科学问题**：视频 DiT 生成的人物在转头或微表情时为何频繁“眼神失焦 / 像吃了药一样呆滞飘移”？
  - 三条干净的物理/表征根因：① **子 Token 眼部量化**（8×8 VAE × 2×2 Patch 使 2–4px 瞳孔偏移 = 10°–15° 视线偏转落在亚 Token 尺度）；② **缺失前庭眼反射（VOR）**（转头时虹膜随脸部纹理刚性平移，不会反向补偿锁住镜头）；③ **4× 时间 VAE 扫视混叠**（真人 30–80ms 快速扫视短于单个 4 帧潜块，被糊成慢速飘移）。
- **学术界最新进展（截至 2026.11）**：现有凝视控制集中在静态图重定向（`DiT-Gaze 2511.11231`）或语音 3D 网格（`TalkingEyes 2501.09921`），**原生视频 DiT 零机理剖析（潜力 8.2/10，CVPR / SIGGRAPH）**。

### C. 视频 RLHF & 原生 AV-DiT 底层基础问题（含 2026.11 反证纠偏）

#### 6. `C1*` — 视频 RLHF 为什么越训越“僵”（能力混淆偏好与静态吸收陷阱）
- **想研究的科学问题**：就算 Reward Model 100% 精准（甚至直接用真实人类逐轮标注），视频 RLHF 是不是照样会动作坍缩？核心假设是**能力-偏好混淆**：弱模型动作一大就崩坏，人类被迫把票投给静态安全样本 $\to$ 真实人类偏好出现“弱模型负斜率、强模型正斜率”的**能力阈值符号反转** $\to$ 在线 RL 陷入静态吸收陷阱。
- **学术界最新进展与反证边界（截至 2026.11）**：
  - **依然零撞车**：无任何论文在 `VideoGen-RewardBench` / `VideoFeedback2` / `VisionRewardDB` 上检验过纯人类偏好的“能力层级符号反转”。
  - **必须正面区分的两大强竞争解释**：
    1. **`arXiv:2611.22495`（2026.11）**：用“逐级冻结帧阶梯”证明 `VideoReward`/`VideoScore` 给冻结帧打分更高，归因于 **VLM 空间编码强、时序编码弱（信噪比不对称）**；
    2. **`DynaForcing`（2026.08）**：证明**完全不加偏好 RM**，单靠反向 KL 蒸馏也会动态坍缩。
  - **关键验证方式**：先在纯公开人工数据做能力层级检验（排除 VLM 与 RL 算法），再做同架构 `RM_pooled` vs `RM_deconfounded` 替换实验。

#### 7. `C3*` — 原生音视联合 DiT 的静音幻觉张嘴与说话-表情纠缠机理
- **想研究的科学问题**：原生 AV-DiT（`LTX-2.3`、`Veo 3`、`MiniMax-H3`、`DreamX-Creator`）在静音或旁人说话时为何忍不住让静止人脸“乱张嘴”？且压掉嘴动时为何容易把自然微笑、4–6Hz 大笑一起冻成“死嘴”（在二次元立绘上甚至会强行长出 3D 肉感嘴唇）？
- **学术界最新进展与关键纠偏（截至 2026.11）**：
  - 社区（`LTX-2.3` Reddit/ComfyUI、`Veo 3`）和论文均已证实这是行业普遍真痛点，且截至 2026.11 **整个原生 AV-DiT 领域至今零篇机理可解释性 / 注意力头电路论文**；
  - **关键反证纠偏**：2026.11.13 刚发的 **`Découpage`（`arXiv:2611.18866`）** 在 `LTX-2.3` 上跑辅助 `<NO SPEECH>` 音频通路**仅增加约 `1.56%` 耗时（并非 2×！）**；`The Attention Triangle`（`2609.03586`）约 2.5× 耗时 + SAM 掩码；`Soundwich`（`2610.00691`）做多轨音频分离。
  - **真正剩余的硬空白**：上述三篇全把问题当成跨模态 `A→V` 路由，**全部漏掉了**：① 即使在 `<NO SPEECH>` 下仍由视频内部自注意力/文本先验驱动的 **Pathway B 静音说话先验**；② **杀掉说话却保住微笑/大笑的精细正交解耦**；③ **单流稠密 AV-DiT（`MiniMax-H3` / `JavisDiT++`）与双流统一白盒机理**。

#### 8. `Z1*` — 视频扩散 RL 中速度场 KL 锁紧却依然 Reward Hacking（中间层表征遗忘 `REPA-Forgetting`）
- **想研究的科学问题**：DiT 输出层存在 24×–80× 秩坍缩（`1536/5120 → 64`）且后半段层能补偿中间层漂移，导致输出速度场 KL 很小时，中间层的物理/语义表征已被 RL 悄悄破坏。
- **学术界最新进展与反证边界（截至 2026.11）**：
  - **零撞车**：`REPA` / `VideoREPA` / `iREPA` / `PhysAlign` 全在预训练/SFT 阶段；`GRPO-Guard` / `Flow-DPPO` / `GARDO` / `DDRL` / `Flow-OPD` / `DiffusionART` 全在输出速度空间；`CoRe`（`2609.36245`）只从 LRM 侧看隐状态 OOD。
  - **高证伪风险**：NeurIPS 2025 **`HASTE`（*"REPA Works Until It Doesn't"*, `2505.16792`）** 证明后期继续挂 VFM 对齐会因判别式教师容量限制反伤生成；且必须证明表征遗忘在 **`DDRL + Flow-DPPO`** 下依然存在，且 VFM 子空间能击败模型自身的 **`Top-r PCA(h_ref)`**。
