## 一、 四幕故事线逐一拆解

### 1. `Anime-P2`（SIGGRAPH / CVPR 王牌）：平涂赛璐璐图形阴影重打光
- **第一幕 · 3 秒钩子（Hook）**：
  - 首页图放一张 2D 二次元立绘，分别做左侧暖夕阳与背后强逆光：展示 `IC-Light`、`LightLab (2505.09608)`、`UniRelight (2506.15673)` 把 2D 纸片人毁成满脸写实鼻影与塑料反光的 3D 娃娃，并直接展示“先跑 `IC-Light` 再套硬色阶卡通滤镜”只会量化出极丑锯齿鼻影块。
- **第二幕 · 零混淆诊断（Diagnosis）**：
  - 用 `#CC0` VRM + Blender `MToon 1.0` 在同角色同光源下对比「真实 3D 人脸法线」vs「动画抹平人脸法线（Stylized Face Normals）」：证明写实重打光模型在二次元上翻车的根源**不只是“阴影不够硬”，而是光照几何本身（3D 鼻梁/眼窝凹凸）与色彩空间（蓝/粉发在暖光下灰绿脏化）全面错位**。
- **第三幕 · 极简概念解法（Clean Solution）**：
  - **两步直觉解耦（几何阴影布局 $\to$ 平涂色相渲染）**：先在干净的 `#CC0` VRM 抹平法线成对数据上，教模型预测**符合 2D 动画美学的简化平涂阴影分布**（抹平鼻翼碎影），再配合**色相偏移暗部 + 原始线稿硬保护**完成重打光（静态图 LoRA + 顺手扩展至光源旋转/角色转头的视频连贯阴影）。无需发明晦涩新公式，核心贡献是把图形学 TA 秘传的“抹平人脸法线 + 图形阴影”第一次带进现代扩散重打光！
- **第四幕 · 真实泛化与单兵周期**：
  - 定量评测用合成 `#CC0` VRM 360° 精确真值，**生态效度评测必须用 30–50 张 CC0/CC-BY 真实人类画师 2D 立绘做盲测 A/B 偏好**。
  - **单兵 `8×H100` 周期**：3.5–4.5 个月（高度可控，极易出视觉封神效果）。

### 2. `Anime-P3`（CVPR / ICCV / NeurIPS 王牌）：超越肌肉 FACS——非生物情绪符号语法
- **第一幕 · 3 秒钩子（Hook）**：
  - 首页图左右对照同一张二次元微笑的脸（嘴巴、眉眼轮廓 1 像素不动，**仅擦掉瞳孔两个白点高光**）：人类 0.1 秒从“阳光开心”翻转为“震惊/失神/黑化”；而前沿 MLLM 嘴上能背出“动漫瞳孔失去高光代表震惊黑化”，看图却依然自信回答“她很开心”；另一侧展示视频/编辑模型接到“震惊得眼神失去高光”指令后，直接把**整个房间灯光关暗**或往平涂脸上画满**写实皱纹**！
- **第二幕 · 三层递进诊断（Diagnosis）**：
  1. **理解侧三步归因**：纯文本文化问答（~95%+）vs. 全图最小反事实对（盲区实锤）vs. 眼部局部放大 & 注意力热图检查（直接衔接 UIUC `Seeing but Not Believing 2510.17771`，区分“深层注意到了但解码没信”还是“视觉编码器压根没看见非生物符号”）；
  2. **生成/编辑侧失败分类**：统计 `Qwen-Image-Edit` / `FLUX-Kontext` / `Wan2.2` / `LTX-2.3` 的**物理字面化（关房间灯）**与**写实生物化（贴皱纹/肉唇）**比例；
  3. **三语文化切片（中 / 日 / 英）**：衔接 2026 大热文化偏置线（`VisionValueBench` / `CuRe` / `CulturalFrames`），测日语原词（*ハイライトのない目 / ジト目 / 照れ線*）vs. 中文 vs. 英文翻译对理解与生成的巨大差异！
- **第三幕 · 极简概念解法（Clean Solution）**：
  - **理解侧**：测试免训练局部符号注意力唤醒（类似 `Vea` / 局部视觉提示）+ 极少量最小反事实对微调，证明只需极轻量的“符号视觉接地”就能唤醒模型本就具备的文化知识；
  - **生成侧**：对比“抽象情绪词”与“显式 2D 局部图形操作词（如：仅擦除双瞳白色高光点、保持环境光照不变）”的改写对照，清晰量化多少失败来自**文本编码器物理歧义**、多少来自**扩散生成器生物先验**，再配极轻量符号编辑适配器收尾。
- **第四幕 · 真实泛化与单兵周期**：
  - 合成最小反事实对（像素级零混淆 + 人类盲测一致性 >90% 筛选）+ 公开合规漫画/开源立绘真实样本验证。
  - **单兵 `8×H100` 周期**：3–4 个月（全清单**科研风险最低、最快出震撼曲线**，哪怕纯诊断+轻量唤醒也极具顶会口碑）。

### 3. `Anime-P6`（CVPR / ICCV / NeurIPS 极简王牌）：剥离光影后，大模型还懂 2D 遮挡前后关系吗？
- **第一幕 · 3 秒钩子（Hook）**：
  - 首页图放**同一套 3D 网格与精确 Z-Buffer** 导出的 4 张平行图：`真实物理 PBR` $\to$ `卡通阴影` $\to$ `纯平涂 2D 动漫` $\to$ `纯黑白线稿`。在刘海遮眼、手托下巴、围巾叠层、双人搭肩的 T 形交点上，人类 4 级全接近 99% 秒答谁在前谁在后；而 `Depth Anything V2 (2406.09414)`、`VGGT (2503.11651)` 与 `Qwen3-VL` 在剥离阴影后的断崖跌落曲线一目了然！
- **第二幕 · 物理实验级零混淆诊断（Diagnosis）**：
  - 零人工主观打分、零姿态构图混淆；分别在“局部自遮挡（刘海/手/衣领）”与“双人交互遮挡（搭肩/交错手臂）”两个切片上，精确定位现代 3D/空间基础模型对**光影渐变捷径** vs. **格式塔 T 形交点（T-Junctions）**的真实依赖占比。
- **第三幕 · 极简概念解法（Clean Solution）**：
  - **同几何跨渲染域自监督对齐（Same-Geometry Cross-Render Self-Distillation）**：无需任何昂贵人工标注！直接利用 Blender 同一 3D 姿态成对渲染的 `Flat-2D / Line-Art` 与精确 3D 深度/遮挡真值（或 PBR 教师表征），用极轻量 LoRA 教 `Depth Anything V2` / `VGGT` / `Qwen3-VL` 学会从纯线条 T 形交点恢复正确遮挡序——并验证它不仅不伤真实照片精度，还能零样本泛化到**真实人类手绘 2D 动漫插画**，直接赋能动漫图层拆解与空间推理！
- **第四幕 · 真实泛化与单兵周期**：
  - 合成 4 级精确真值 + 真实手绘 2D 动漫插画 T 形交点人工验证集（200 对部件遮挡关系，半天即可标完）。
  - **单兵 `8×H100` 周期**：2.5–3.5 个月（**全清单周期最短、指标最客观、审稿人最难挑刺**！）。

### 4. `Anime-P4`（NeurIPS / ICLR / CVPR 表征王牌）：互换服装 / Q 版 / 黑白漫画后的“抽象身份 vs 服饰捷径”
- **第一幕 · 3 秒钩子（Hook）**：
  - 首页图把「角色 A 穿角色 B 的一模一样衣服」以及「角色 A 的 2 头身 Q 版 / 黑白漫画」放进 `DINOv2`、`SigLIP 2`、`deepghs/ccip` 和 `Qwen3-VL`，直观展示“认衣不认人”混淆矩阵，以及 `FLUX-Kontext` / `Qwen-Image-Edit` 一脱原衣服就把角色刘海和脸型洗成路人的“脱衣失忆症”。
- **第二幕 · 四维正交诊断（Diagnosis）**：
  - 角色 × 服装 × 头身比（8 头身/2 头身 Q 版）× 色彩域（彩图/黑白漫画），逐轴剥离“服饰捷径”、“色彩捷径”和“头身比例捷径”（并对比全身图 vs 裁脸图，正面化解“直接裁脸就行”的质疑）。
- **第三幕 · 极简概念解法（Clean Solution）**：
  - **反事实硬负样本对比去偏（Counterfactual Outfit-Swap Debiasing）**：在 `#CC0` VRM 四维正交图上，显式把「A 穿 B 衣」与「A 穿 A 衣」拉近，同时把「A 穿 B 衣」与「B 穿 B 衣」强行推远作为硬负样本！15 分钟轻量微调就能测试能否把 `SigLIP 2` / `CCIP` 的服饰捷径连根拔起，并验证能否作为更好的评估/引导信号提升跨形态编辑保真度。
- **第四幕 · 真实泛化与单兵周期**：
  - 合成四维正交矩阵 + 合规开源多服装/同形态角色真实手绘验证集。
  - **单兵 `8×H100` 周期**：3–4 个月（前提是必须先跑完 2 小时试金石确认 `CCIP` 与 `Qwen3-VL` 真存在显著翻车！）。

### 5. `Anime-P1`（NeurIPS / ICCV 音视专精）：原生音视跨模态言行不一（傲娇 / 黑化 / 强颜欢笑）
- **第一幕 · 3 秒钩子（Hook）**：
  - 首页图展示给 `LTX-2.3` / `DreamX-Creator` 喂入“凶狠不满语音 + 害羞脸红躲闪（傲娇）”和“甜美温柔语音 + 微笑但眼无高光（黑化）”时，原生 AV-DiT 发生的**模态覆写**（凶声音把脸红抹成暴怒，或甜声音把黑化眼变回天真大笑）。
- **第二幕 · 诊断**：量化 `2×2` 同向 vs 反差下的**模态覆写矩阵**，并通过“纯文本双模态提示” vs “锁定真实开源语音条件”拆开文本编码器混淆与 `A ↔ V` 跨模态注意力覆写。
- **第三幕 · 极简概念解法**：针对原生双流 AV-DiT 做**区域-模态选择性解耦门控**——只在嘴部音素同步区域保持 `A → V` 强耦合，而在上半脸（眼/眉/脸红）降低音频情绪特征的强制覆盖权重，让声音与表情可以独立表达潜台词！
- **第四幕 · 单兵周期**：3.5–4.5 个月（可与 `S5` 画外音视因果共用全部 `LTX-2.3` / `DreamX-Creator` 推理基础设施）。

## 三、 最务实的单兵启动策略（零沉没成本）

不要现在在纸面上空猜哪一个最好！既然 **`P2`、`P3`、`P6`、`P4` 全部共用同一套 `#CC0` VRM + 无头 Blender (`MToon 1.0`) 渲染引擎**（详见 [`07_shared_counterfactual_engine_spec.md`](./07_shared_counterfactual_engine_spec.md)）：

2. **第 1 周内（总计 6–8 小时零训练推理）**：依次跑完 **`P6`（1h）$\to$ `P3`（2h）$\to$ `P2`（2h）$\to$ `P4`（2h）** 的试金石；
3. **凭真实验证曲线一锤定音**：哪个问题的真实失效现象**最反直觉、肉眼最震撼、基线崩得最彻底**，就直接锁定它作为第一篇 CCF-A 主战论文，其余 3 个干净归档留作后续第二篇！
