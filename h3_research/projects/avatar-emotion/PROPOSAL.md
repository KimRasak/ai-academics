## 一分钟版

现在的开源"数字人"， lip-sync（唇形同步）已经以假乱真，但有一个被普遍忽视的缺陷：**说话人声音里的情绪，脸上完全看不出来**。你对着麦克风愤怒地喊，屏幕里的数字人依然面无表情地"念"出来。

我们用一套自动评测管线测量了这个现象——158 段视频、4 个随机种子，人脸的表现力均值只有 **0.079**（满分 1.0），而且不管语音是愤怒、高兴还是恐惧，这个数字几乎不变。作为对照，同一段语音的**声音**里情绪信号非常充沛（0.76–0.80）。一句话总结：**声音在演戏，脸在念稿**。

本项目要做三件事：

1. **诊断**：把"面瘫"现象变成可复现的定量结论（已完成大半）；
2. **训练**：能否让数字人学会"跟着声音的情绪做表情"，代价（长相变化、唇形变差）有多大（本轮主攻）；
3. **验证**：自动指标靠谱吗？用小规模人评来校准（协议已设计好）。

## 五分钟版

### 背景：数字人很美，但没有情绪

音频驱动人像生成（audio-driven portrait animation）在近两年快速成熟：EchoMimic、Hallo、EMO、VASA-1 等系统只需一张照片和一段语音，就能生成会说话的人脸视频。直播数字人、虚拟主播、数字客服正在规模化落地。

但这些系统的评价指标几乎只有两样：**唇形对得准不准**（LMD、Sync 置信度）和**画质好不好**（FID、PSNR）。**情绪**这个维度在主流评测里是缺席的。这在产业上是个隐患——观众对"声画情绪不一致"非常敏感，一个愤怒讲解但面无表情的数字人主播，会直接损害信任感。

### 我们的发现：不是"偶尔面瘫"，是"出生即面瘫"

我们给这个直觉建立了定量证据。做法是让两个现成的判官模型互相问答：

- **SER**（Speech Emotion Recognition，语音情绪识别）听声音：这段话是平静、高兴、愤怒还是悲伤？
- **FER**（Facial Expression Recognition，人脸情绪识别）看脸：视频里的人在表达什么情绪？

如果数字人忠实传递了情绪，两个判官的答案应该一致。我们用共享的四类标签空间计算一致性，外加"表现力"（人脸不是中性的概率）和 GT-match（语音明确是某情绪时，脸是否也被认成该情绪）两个辅助指标。整个流程全自动、可复现、零人工标注。

**测量结果**（针对开源系统 EchoMimic V1）：

| 测量 | 结果 | 解读 |
|---|---|---|
| 人脸表现力 | 0.079 | 92% 的概率是"面无表情" |
| 跨 8 类语音情绪 | 0.073–0.092 | 几乎一条平线：声音情绪传不到脸上 |
| 4 个随机种子 | 标准差 0.012 | 不是抽样波动，是系统性行为 |
| 同批语音的 SER 表现力 | 0.76–0.80 | 声音本身情绪充沛——**瓶颈在渲染端** |
| 2 小时连续会话 | 无恶化 | 是"出生即如此"，不是越播越累 |

我们还做了两组对照实验来排除替代解释：给判官喂真实人脸照片（FER2013），它能正确识别（表情类 0.92–0.99），说明**不是判官失灵**；给生成端换一张微笑的参考照片，表现力只从 0.065 升到 0.14，说明**不是参考图的问题**。结论：塌缩发生在生成模型内部。

### 研究问题

- **RQ1 诊断**：塌缩是否存在？是"始终中性"还是"偶发表情但不匹配"？（已回答：静态贫瘠）
- **RQ2 度量**：上述自动指标是否有效？能否被人评校准？（管线已建，人评待做）
- **RQ3 训练**：情绪忠实性能否通过训练获得？哪种监督信号有效？代价多大？（**本轮主攻**）
- **RQ4 泛化**：结论是否跨数据集、跨会话时长、跨参考身份成立？

### 训练方案：四条路线的系统消融

我们选择 LoRA（Low-Rank Adaptation，只训练注入模型的小矩阵，不动原权重）在 EchoMimic 上做情绪忠实化，设计了四个递进的变体：

| 变体 | 一句话说明 | 回答的问题 |
|---|---|---|
| V-A2 | 直接微调（正确的基座 + 正确的训练目标） | 干净管线上，SFT 本身够不够？ |
| V-B2 | 加一个可学习的情绪向量；**推理时由 SER 自动选**，无需人工标注 | 显式条件化能带来情绪选择能力吗？ |
| V-C2 | 损失函数按情绪加权重（情绪样本 1.2–1.5 倍、中性 0.5 倍） | 调损失权重能改善"表情↔长相"的权衡吗？ |
| V-D2 | RAFT 式循环：生成 K 个候选 → 判官打分 → 用最好的续训 | 可验证奖励（RLVR）能买回忠实度吗？ |

奖励函数完全由模型打分，零人工：0.5 × SER↔FER 一致性 + 0.5 × GT-match，再减去身份惩罚（ArcFace 相似度低于阈值就扣分）——即"表情可以学，脸不能换人"。

**预注册假设**（先写下来再跑，避免事后挑指标）：

- H-A：V-A2 的表现力显著高于 0.079 基线，且身份相似度 ≥ 0.80
- H-B：V-B2 的 GT-match 显著高于 V-A2（条件化带来选择能力）
- H-C：V-D2 的 GT-match 与一致性进一步提升（奖励循环有效）
- H-D：所有变体的唇同步不低于基线（学情绪不毁唇形）

### 方法学副产品：我们踩过的三个"静默陷阱"

复现训练管线的过程中，我们发现了三个会让训练"看起来在跑、结论完全错误"的坑：

1. **漏加载微调权重**：只加载通用底座、忘了加载官方微调过的 denoising 权重，生成的脸依然像脸，但身份彻底错乱——不细看根本发现不了；
2. **扩散训练目标写错**：忘了对干净样本加噪（`add_noise`），损失函数恒等于 1.0、曲线平稳——看起来一切正常，实际模型什么都没学；
3. **音频特征管线静默失败**：内部调用 ffmpeg 但 PATH 没配，每个样本都失败、被悄悄吞掉，数据集变成空的，loss 显示 0.0000。

这三个坑都有"表面正常"的共同特征，是开源复现浪潮中反复出现的失败模式。我们已全部修复并用对照实验验证，相关记录将整理成 reproducibility 方向的独立投稿素材。

## 风险与应对

| 风险 | 应对 |
|---|---|
| 即使在干净管线上，SFT 仍是"抬表情、掉身份" | 叙事转向"表情-身份权衡的帕累托前沿"：benchmark 与诊断升为主贡献，训练变为分析性证据 |
| 情绪嵌入/奖励循环无法恢复情绪选择能力 | 加强条件注入方式（逐帧加性嵌入）；明确写入 limitations，留作后续工作 |
| 共享 GPU 被外部作业抢占或污染 | 已实现崩溃自动续训；关键实验错峰；必要时按 §资源申请独占卡 |
| 判官在"生成脸"上的校准未知 | 补一个 50 张生成脸的人工标注校准子实验 |
| 人评只有 n=10，统计功效有限 | 以效应量与置信区间呈现，定位为"构念效度检验"而非显著性声明 |

## 资源需求（兼作 GPU 申请理由）

**现状**：与其他用户共享 8×H100 节点，单作业实际可用显存约 20GB。

**为什么需要独占卡**：

1. **外部作业已三次污染 CUDA 上下文**（跨两张不同 GPU 出现同样的底层错误，已排除我们代码的问题）。自动续训能把每次中断的损失从"整轮作废"降到"从上个检查点继续"，但每次仍损失 10–20 分钟，且故障节奏不可预测；
2. **算力账目**：四个变体 ×（训练 5.3 小时 + 评测约 42 段视频）≈ 30 GPU 时；V-D2 的 180 段候选生成 ≈ 8 GPU 时；2 小时矩阵每变体 ≈ 0.5 GPU 时。合计约 40–60 GPU 时的核心计算，独占时约 3 周可全部完成；
3. **申请配置**：2 张独占 H100 × 3 周。若只能给 1 张：计划顺延 1.5 周，并砍掉 V-C2（保留 V-A2 / V-B2 / V-D2 三点消融，结论完整性基本不受损）。
