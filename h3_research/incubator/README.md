# Research Incubator

这里保存尚未成为独立项目的候选方向、查重记录和大规模文献调查。

`topic-survey-2026/` 包含蒸馏、种子一致性、流式生成、avatar 等方向的选题演化：

- `ideas/`：多轮候选 idea 与最终筛选记录。
- `proposals/`：尚未立项的完整训练方案。
- `research/`：H3 选题调研和检索词。
- `references/`：Scholar/HF 调研结果；浏览器 profile 已移入根 `.cache/`。
- `experiments/`：候选方向的验证性实验。

项目一旦正式立项，应迁入 `projects/`，而不是继续在此累积实验产物。
