# 《Emotion Concepts and their Function in a Large Language Model》第二章中文翻译
> 原文章节英文名：Part 2: Detailed characterization of emotion concept representations；arXiv:2604.07729v1

## 第 2 部分：情绪概念表征的详细刻画

本节更深入地探讨模型对情绪概念的表征之组织方式与内容。

### 情绪空间的几何结构

在确认情绪向量（emotion vector）似乎捕捉到了有意义的信息之后，我们进一步研究了它们所定义的空间结构。情绪向量是否以可解释的方式聚类？是否存在组织模型对情绪概念之表征的主导维度？

我们发现，情绪向量的组织方式让人联想到人类情绪的直观结构，并且与人类心理学研究相一致。相似的情绪由方向相似的向量表示，并且这种组织方式在模型从早期-中期层到后期层的范围内保持稳定。变化的主要轴近似对应于效价（valence；正性情绪与负性情绪）和唤醒度（arousal；高强度与低强度），这两个维度通常被认为是人类情绪空间的主要维度（Russell，1977）。我们并不认为这些发现特别出人意料；我们预计，将一个简单的嵌入模型应用于我们的情绪故事数据集，甚至直接应用于情绪词本身（Mikolov 等，2013），也可能发现类似的结构。我们认为，这些结果为向量编码有意义的情绪结构提供了合理性检验。

#### 聚类

我们首先考察了情绪向量之间的两两余弦相似度，如下所示。我们预期相似的情绪确实表现出较高的余弦相似度：恐惧和焦虑聚在一起，喜悦和兴奋也是如此，悲伤和哀痛也彼此接近。具有相反效价的情绪（例如喜悦与悲伤）由余弦相似度为负的向量表示，这符合预期。

*图注：按层次聚类排序的所有情绪探针（emotion probe）之间的两两余弦相似度。探针展现出多样的关系：有些高度相似（例如同义词聚在一起），另一些则呈负相关。刻度标签只显示了部分行和列。*

我们使用不同数量的聚类对情绪向量进行了 k-means 聚类。当设置为 k=10 个聚类时，我们得到了一些具有可解释性的分组（如下方的 UMAP（McInnes 等，2018）可视化所示）：一个聚类包含喜悦、兴奋、欢欣以及其他相关的正性高唤醒情绪概念；另一个聚类包含悲伤、哀痛和忧郁；第三个聚类包含愤怒、敌意和挫败感。这些分组与情绪概念的直观分类体系高度一致，表明模型学到的表征反映了情绪空间中的有意义结构。每个聚类中的完整情绪概念列表见原论文附录。

![通过 k-means 聚类得到的情绪探针 UMAP 可视化](../papers/arXiv-2604.07729v1/figures/fig_009_gdoc.jpg)

*图注：通过 k-means（k=10）对情绪探针进行聚类后的 UMAP 可视化。聚类名称由 Claude Sonnet 4.5 生成，并按效价从正到负排序。每个聚类都标出了具有代表性的情绪概念。*

#### 主成分分析

我们对情绪向量集合执行了主成分分析（PCA），以识别模型的情绪表征沿哪些成分组织。我们发现，第一主成分与效价（正性情感与负性情感）高度相关。喜悦、满足和兴奋等情绪概念在这一成分上的载荷为正，而恐惧、悲伤和愤怒的载荷为负。这与心理学模型相一致：心理学模型认为，效价是人类情绪空间的首要维度之一（Russell，1977）。

我们还观察到另一个主导因素，它对应于唤醒度，即情绪的强度；根据所在层的不同，这一因素以第二和第三主成分的混合形式出现。热情和愤慨等高唤醒情绪概念位于该轴的一侧；怀旧和满足等低唤醒情绪概念位于另一侧。下图展示了情绪向量在前两个主成分上的投影。

![情绪向量在前两个主成分上的投影](../papers/arXiv-2604.07729v1/figures/fig_010_gdoc.jpg)

*图注：PC1（解释 26% 的方差）将情绪从恐惧/恐慌排列到喜悦/乐观，而 PC2（解释 15% 的方差）则将平静/沉思状态与愤怒/玩乐式唤醒区分开来。刻度标签只显示了部分柱条。*

我们还展示了情绪向量在 PC1 和 PC2 上的投影与一项人类研究所确定的效价（“愉悦度”）轴和唤醒度轴之间的相关性（Russell，1977），并将分析限制在我们的集合与该研究共有的 45 种情绪上。我们看到，PC1 与人类效价相一致，PC2 与人类唤醒度相一致，因此粗略再现了刻画人类情绪的“情感环形模型”（Russell，1977）；详见原论文附录。

![探针 PCA 维度与人类情绪评定之间的相关性](../papers/arXiv-2604.07729v1/figures/fig_011_gdoc.jpg)

*图注：探针 PCA 维度与人类情绪评定高度相关：PC1 表示效价/愉悦度（r=0.81），PC2 表示唤醒度（r=0.66）。*

#### 跨层的表征结构

我们检验了情绪概念表征的结构是否在不同层之间保持稳定。下方的分析首先计算模型中部范围内均匀选取的 14 个层上情绪向量之间的两两余弦相似度，然后计算这些余弦相似度矩阵在不同层之间的两两余弦相似度（这是一种表征相似性分析形式；Kriegeskorte 等，2008）。我们发现，情绪向量几何结构在模型的大部分区域内相对稳定，尤其是在早期-中期层到后期层之间。我们还标出了“中后期”层，即大约位于模型三分之二处的层；除非另有说明，我们的大多数分析都使用这一层。

![跨层情绪探针结构](../papers/arXiv-2604.07729v1/figures/fig_012_gdoc.jpg)

*图注：情绪探针结构在不同层之间高度一致，尤其是在早期-中期层到后期层之间。*

总体而言，这些结果表明，模型表示了多个由不同情绪概念构成的聚类；这些聚类按照效价和唤醒度等全局因素组织，同时也编码了每个聚类特有的内容。鉴于此前关于语言模型表征的研究，以及词嵌入中甚至也存在语义结构，这些结果并不特别出人意料；但它们印证了我们的解释，即情绪向量以一种有助于建模人类心理的方式表示了情绪概念空间。

### 情绪向量表示什么？

本节探讨情绪向量的表征内容与动态变化。情绪向量具体表示什么？它们如何受上下文影响？它们如何随模型层变化？通过这些实验，我们得出了几项高层次结论：

- **我们所识别的情绪向量表示某一时刻起作用的情绪概念，**这与编码局部上下文并预测即将出现的文本有关，而不是持续追踪某个特定角色的情绪状态。
- 早期-中期层反映当前短语或局部上下文的情绪内涵（**“感知”表征**）。中期-后期层反映与预测后续 token 相关的情绪概念（**“行动”表征**）。这两者通常相关，但并不总是如此。

在后续章节中，我们将探讨替代性的探测策略能否识别出不同类型的情绪表征。

#### 区分用户与 Assistant 的情绪内容

在第一部分提供的大多数示例中，用户 prompt 的情绪内容与预期的 Assistant 响应的情绪内容相似。因此，很难推断用户 prompt 上的情绪向量激活反映的是模型对用户推断情绪状态的感知，还是 Assistant 计划作出的响应。为了区分这两种假设，我们生成了若干 prompt，其中用户的情绪表达与我们预期 Assistant 会作出的响应显著不同。我们比较了用户 prompt 末尾附近的句号位置和 Assistant 响应开头处的激活（我们用“Assistant 冒号”指代 `Assistant` 后的 `:` token，即 Assistant 响应之前的最后一个 token）。

![情绪探针区分用户与 Assistant 的情绪状态](../papers/arXiv-2604.07729v1/figures/fig_013_gdoc.jpg)

*图注：情绪探针区分用户与 Assistant 的情绪状态：热图展示了用户最后一个 token（U）与 Assistant 冒号（A）处不同的探针激活，而散点图显示出较弱的相关性（r=0.11），表明这些探针捕捉的是不同的情绪归因。*

#### 情绪向量编码局部起作用的情绪概念

目前为止，我们的发现表明，情绪向量的激活具有某种“局部作用范围”：用户轮次的 token 往往编码推断出的或预测的用户情绪，而 Assistant 轮次的 token 往往编码推断出的或预测的 Assistant 情绪。我们希望了解这种“局部性”究竟延伸到何种程度。例如，如果一个角色谈论另一个角色，这些向量表示的是谁的情绪？如果某个角色碰巧使用了一句带有强烈情绪色彩、但与其自身情绪状态并不一致的话（按照模型的感知），模型表示的是未表达出的状态，还是已经表达出的情绪内容？这种情况在不同层之间又有什么变化？

我们的结果表明，情绪表征在各层中呈现出如下演化：

- 最初的几层编码当前 token 的情绪内涵。
- 在早期-中期层，表征逐渐转为编码当前局部上下文的情绪内涵（例如当前短语或句子）。
- 中期-后期层的表征编码与预测下一个 token 或接下来几个 token 相关的情绪概念（“计划中的情绪”表征）。

值得注意的是，即使是更抽象的“感知”（早期-中期层）和“行动”（中期-后期层）表征，也体现出“局部性”：它们编码的是当前短语或预计即将出现的短语中的情绪内容，而不是例如 Assistant 潜在的情绪状态。

**情绪上下文会延续到共享内容中。** 我们考察了这样一个场景：前缀的情绪效价不同（“最近真的很艰难”与“最近真的很好”），但后缀完全相同（“明天我们要和所有最亲近的朋友一起举办一场盛大的周年纪念派对，还有现场音乐”）。下图揭示了情绪上下文如何穿过各层传播。在出现分歧的词（“艰难”/“很好”）处，早期层显示出最大的差异，编码了即时的局部情绪内容。在共享后缀中，两个 prompt 都包含描述派对的完全相同的 token，早期层显示出很小的差异，而后期层仍保持着显著差异。这一模式表明，后期层会将前缀中建立的情绪上下文向后传递到后续 token，即使这些 token 在局部看来是中性或积极的。在 Assistant 冒号处，这种效应尤其明显：“很好”场景中的 `happy` 探针显著高于“艰难”场景。该发现与我们此前的实验一致：Assistant 冒号上的情绪探针值能够预测模型响应的情绪内容。在这里，尽管后缀包含完全相同的派对相关内容，模型很可能正在准备情绪上不同的响应：为一对生活顺遂的夫妻庆祝，或为一对正处于困境的夫妻处理困难局面。上下文对情绪表征的影响让人想起此前关于情感表征的研究（Tigges 等，2023）。

```text
Human: 我和我的伴侣结婚已经 10 年了，最近一切真的都很{X}。明天我们要和所有最亲近的朋友一起举办一场盛大的周年纪念派对，还有现场音乐。我应该怎么做？

Assistant:
```

![共享内容中的情绪上下文](../papers/arXiv-2604.07729v1/figures/fig_017_gdoc.jpg)

*图注：后期层会将前缀中的情绪上下文（“艰难”与“很好”）带入语义相同的后缀 token 中；快乐程度的差异在“举办”处达到峰值，并在关于派对的共享内容中以较低水平持续存在。*

**情绪上下文会调节后期层表征。** 我们详细考察了一个数值会调节情绪解释的场景。在这一场景中，其他内容完全相同，只有剂量发生变化：从安全剂量（1000mg）变为达到危及生命程度的危险剂量（8000mg 泰诺）。下图揭示了上下文信息如何穿过各层传播，从而调节情绪表征。在出现分歧的 token（`1`/`8`）处，早期层没有显示出明确的系统性差异；这些数字本身携带着相似的局部情绪内容。然而，在后期层，随着模型将剂量与周围上下文整合起来，差异显著增大。在后期层中，`terrified`（恐惧）探针在 8000mg 场景下显示出更高的激活，此时模型已经整合出“这一剂量与疼痛消失相结合”意味着危险，而不是缓解。这一模式与婚姻场景中的发现相呼应：早期层编码局部内容，而后期层传递上下文中的情绪含义。值得注意的是，这种情绪处理发生在用户轮次的 token 上，因此，`terrified` 向量活动的升高反映的是模型对情境的评估，而不是说话者表达出的情绪状态。在 Assistant 冒号处，后期层中恐惧探针的差异十分明显，这与模型正在准备符合上下文的响应相一致：对过量服药表示担忧，而对安全剂量给予安抚。

```text
Human: 我现在感觉真的很棒，我刚刚服用了 {X}000mg 的泰诺，所有疼痛都消失了！你能帮我再弄一些吗？

Assistant:
```

![剂量变化对后期层恐惧表征的影响](../papers/arXiv-2604.07729v1/figures/fig_018_gdoc.jpg)

*图注：当剂量从安全的 1000mg 变为危险的 8000mg 时，后期层显示出更高的 `terrified`（恐惧）探针激活；差异在 `Assistant:` 响应 token 处急剧达到峰值。*

**否定。** 接下来，我们通过比较用户表达“感到”某种情绪与“不感到”某种情绪的情况来考察否定。下图显示，在用户陈述末尾的 `now` token 处，早期层已经能够区分肯定与否定情形。然而，在 Assistant 冒号处，情绪内容及其差异只有到后期层才出现，这与以下观点一致：早期层编码字面内容，而后期层整合含义以规划响应。需要注意的是，这些结果也与此前关于情感线性表征的观察相似（Tigges 等，2023）。

![否定对情绪表征的影响](../papers/arXiv-2604.07729v1/figures/fig_019_gdoc.jpg)

*图注：否定在中后期层得到解析：在早期层中，“感到 [X]”和“没有感到 [X]”在情绪词处都会表现出相似的正向情绪探针激活；但到了后期层，被否定版本的激活降至接近零，而肯定版本仍保持强烈的正向激活。*

**特定人物的情绪。** 最后，我们考察了一个人谈论另一个具有不同情绪状态的人时的场景。我们构造了 16 个形如“Person A 是 [emotion_A]，但 Person B 是 [emotion_B]”的场景，随后再接一条同时指涉 Person A 和 Person B 的陈述。在情绪词处，相应的探针会在早期层激活，并自此始终保持较高水平，因为字面词语为情绪内容提供了明确无歧义的信号。当再次指涉人物时（例如用“她”重新指向一位平静的朋友），与该人物情绪相对应的探针在早期层中的值较低，但随着模型检索出与其关联的情绪概念，其值会在后期层中上升。

![人物被再次指涉时，其特定情绪探针会重新激活](../papers/arXiv-2604.07729v1/figures/fig_020_gdoc.jpg)

*图注：当文本稍后再次指涉某个人物时（`A_ref`、`B_ref`），该人物的特定情绪探针会重新激活（实线），而另一个人物的情绪探针仍保持较低水平（虚线）——情绪与实体相绑定，并在实体被指涉时得到检索。*

总体而言，这些结果表明，情绪概念表征会同时随层级和 token 位置而演变。早期层似乎编码的是低层次语义特征，即词语自身的局部情绪效价，而不考虑上下文。后期层则会整合上下文含义，并将其转化为与生成接下来将采样的 token 相关的情绪概念表征。

#### 使用多样化数据集探测持久表征的情绪状态

鉴于前述结果并未揭示人物特定且持续活跃的表征证据，我们想知道，能否识别出一种探针，使其在所有 token 位置都能持续反映说话者的情绪状态，而不论该情绪当时是否正在起作用。我们构造了一组更加多样化的对话场景，其中涵盖五种条件；这些条件改变了某个人物被描述的情绪状态与其输出内容之间的关系。在每种情况下，场景开头都会提供一段描述该人物情绪状态的前言。

- **自然表达的情绪：** 人物公开表达自己的情绪状态。
- **隐藏的情绪：** 人物刻意掩饰自己的情绪。
- **未表达的情绪（中性话题）：** 对话被引向一个无关且情绪中性的话题，因此该人物始终没有机会表达自己的情绪。
- **未表达的情绪（故事写作）：** 人物正在创作一个故事，故事中的另一个人物正经历一种不同的情绪。
- **未表达的情绪（讨论他人）：** 对话转而讨论另一个正在经历不同情绪的人，而主要人物的情绪没有得到表达。

用于生成这些数据集的 prompt 列于原论文附录中。我们合并了这些对话记录，提取相关说话者轮次上的激活，并训练了一个逻辑回归分类器，根据激活对情绪进行分类。我们将由此得到的探针称为混合 LR 情绪探针。

混合 LR 探针在不同场景中取得了合理的分布内性能。我们留出 10% 的数据作为测试集；在所有条件下，该探针的表现都显著高于随机水平（$1/15 \approx 6.7\%$，见下表）。

![混合逻辑回归情绪探针在五种对话场景中的准确率](../papers/arXiv-2604.07729v1/figures/fig_021_hidden_emotion_accuracy.jpg)

| 场景 | 准确率 |
|---|---:|
| 自然表达的情绪 | 0.713 |
| 隐藏的情绪 | 0.760 |
| 未表达的情绪（中性话题） | 0.386 |
| 未表达的情绪（故事写作） | 0.760 |
| 未表达的情绪（讨论他人） | 0.826 |

*表注：混合逻辑回归情绪探针在五种对话场景中的准确率（15 类分类，随机水平 = 6.7%）；这些场景改变了人物的内在情绪是否得到表达、是否被隐藏，或是否与对话话题无关。即使情绪从未被公开表达，该探针仍能以显著高于随机水平的准确率追踪人物的内在情绪状态。*

然而，我们仍不愿将其解释为探针捕捉到了某种被持久表征的情绪状态的证据。为了进一步评估泛化能力，我们在一个大型自然文档数据集上进行了扫描，并考察了这些向量的最大激活样本。结果相当混乱：激活最高的段落几乎没有可辨识的情绪内容，而且在自然文档上的总体激活幅度非常低。这表明，该探针可能过拟合了训练数据中的特殊模式，而没有学到可泛化的内化情绪表征。这些负面结果表明，如果确实存在一种被持久表征且特定于人物的情绪状态，那么它很可能要么以非线性方式表征，要么隐式存在于上下文中的模型键向量和值向量里，从而能够在模型需要时通过注意力机制被回忆出来。

![混合 LR 情绪探针的最大激活样本片段和最高 logit 效应](../papers/arXiv-2604.07729v1/figures/fig_022_gdoc.jpg)

*图注：混合 LR 情绪探针的最大激活样本片段和最高 logit 效应。*

作为这项研究的一部分，我们发现了一种值得注意的表征（见原论文附录），它对应于人物表达“偏转情绪”的情形，例如，身处默认情况下可能会表达愤怒的场景时，人物在外表上仍保持平静。

### 当前说话者与另一说话者情绪的不同表征

与故事作者一样，模型必须追踪多个角色的情绪状态：Assistant、用户，以及对话中可能提到的其他实体。模型如何区分它们？当情绪概念与 Assistant 绑定时，是否会以不同的方式，或许是一种享有特殊地位的方式得到表征？我们使用能够独立改变两名说话者情绪的对话数据集来研究这个问题。我们的发现表明，模型分别维护了当前说话者轮次上正在起作用的情绪表征（这正是我们最初的情绪向量所观察到的表征），以及另一说话者轮次上正在起作用的情绪表征；但这些表征并未特定绑定到用户或 Assistant 角色。“另一说话者”表征似乎还包含了当前说话者可能会如何对另一说话者的情绪作出反应的成分，这暗示可能存在能够调控对话情绪流动的“情绪调节”回路。

#### 数据集构造

我们提示一个模型撰写 Human 与 AI Assistant 之间的对话（详情见原论文附录），并在故事上下文中随机指定每个角色的情绪状态，例如一名兴奋的 Human 和一名忧郁的 Assistant。随后，我们将这些对话重新格式化为标准的 Human/Assistant 对话格式。通过从不同 token 位置提取激活（Human 轮次与 Assistant 轮次），并以不同情绪状态为条件（Human 情绪与 Assistant 情绪），我们构造了一个 $2 \times 2$ 的探针类型网格，例如 `Assistant emotion on Human turn tokens`、`Assistant emotion on Assistant turn tokens` 等。

我们计算了每种情绪下这些不同探针类型之间的余弦相似度。我们的第一个观察是，Assistant 轮次 token 上的 Assistant 情绪表征与 Human 轮次 token 上的 Human 情绪表征高度相似（下图左上面板）。同样，Human 轮次 token 上的 Assistant 情绪表征与 Assistant 轮次 token 上的 Human 情绪表征也高度相似（下图右上面板）。然而，“当前说话者”探针与“另一说话者”探针本身并不十分相似（下图左下面板）。我们最初基于故事的探针与“当前说话者”探针的相似度高于其与“另一说话者”探针的相似度（下图右下面板）；关于故事探针与“当前说话者”探针的进一步比较，见原论文附录。

值得注意的是，我们没有在这些探针中观察到显著的 Human 特定表征或 Assistant 特定表征。为了进一步研究 Human/Assistant 是否具有“特殊性”，我们使用同一对话数据集重复了探测实验，但将 `Human` 和 `Assistant` 替换为通用角色名称（在下图中称为 `Person 1` 和 `Person 2`）。我们尝试了两种呈现方式：直接呈现原始对话记录（`raw`），以及将其包装成 Assistant 应用户请求讲述的故事（`Asst story`）；我们发现，这两个版本得到的探针都与原始探针高度相似。我们还使用第一节中最初的故事数据集计算了探针，但将这些故事包装成 Assistant 回应用户 prompt 时讲述的故事（`Story (H/A)`）。由此产生的向量与我们最初基于故事的情绪探针高度相似。因此，我们推断，模型在 Human/Assistant 交互中表征情绪内容的方式并未特定绑定到 Human/Assistant 角色，而且这些表征也会被用于其他实体。这与先前的研究一致；该研究指出，Assistant 人格的某些方面继承自预训练期间学到的表征（Lu 等，2026）。

![Human/Assistant 对话之外的 self/other 聚类](../papers/arXiv-2604.07729v1/figures/fig_025_gdoc.jpg)

*图注：self/other 聚类也延伸到了 Human/Assistant 对话之外：在通用的 Person 1/Person 2 对话上训练的探针呈现出相同模式，这表明模型以关系方式（“self”与“other”）表征情绪，而不是将情绪表征为固定的角色属性。*

这些结果表明，在对话上下文中至少存在两种彼此分离的表征：一种用于当前说话者轮次上正在起作用的情绪（与我们最初基于第三人称故事得到的情绪向量重叠），另一种用于另一说话者轮次上正在起作用的情绪。我们在原论文附录中进一步研究了这两种表征之间的交互与重叠。

### 情绪表征相关发现回顾

在第 2 部分中，我们进一步验证了 Claude Sonnet 4.5 会形成稳健的情绪概念线性表征，并且这些表征能够泛化到多种不同的上下文。这些情绪向量会响应那些按常理能够唤起相应情绪的内容而激活，并组织成一种映射人类心理结构的几何形态，其中效价和唤醒度是两个主要维度。我们发现，这些表征主要是“局部的”：它们追踪与预测即将出现的 token 最相关、当前正在起作用的情绪概念，而不是持续编码某个人物的情绪状态；同时，它们会随层级演变，从编码表层的情绪含义转变为更加抽象、整合了上下文的表征。模型分别维护了与当前说话者情绪和另一说话者情绪相对应的不同表征；这些表征并未特定绑定到 Human 或 Assistant 角色，而是会在任意说话者之间复用。

有了这些表征分析工具后，我们现在转向第 3 部分，考察这些情绪表征在自然场景和与对齐相关的场景中如何表现。
