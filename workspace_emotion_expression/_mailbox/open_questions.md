## Q-005｜风格轴能否与情绪强度（arousal）解耦？

- **状态**：open（D-003 后需在纯 2D 设定下重新评估可验证性与预试验资产方案）
- **提出者 / 日期**：AGIC 研究组 / 2026-07-24（全组调研合成，visionary/rigor/critic/builder 一致识别）
- **问题**：候选表达风格轴（克制/外放、眉眼主导/嘴部主导、回避/直视）在回归出 valence-arousal 后，残差风格是否仍可被盲评/分类器稳定区分？即"风格差分"是否独立于已知的强度轴？**在纯 2D 设定下该假设是否仍成立、预试验如何用 2D 资产做？**
- **背景与范围**：这是课题新颖性的命门。若风格轴与 arousal 不可解耦，"表达差分"坍缩为已有强度控制，课题新颖性归零；同时是切换替代方案 B1（AU 级收窄）的触发器。属 Q-004 操作化判据的核心正交性检验。D-003 排除 3D 后，原"3D 表情通道是最干净的 φ 实例化"路径失效，需用 2D 合成/编辑数据构建配对，预试验方案待 rigor/builder 重写。
- **建议接手角色**：rigor + builder；critic 监督盲评协议防捷径。
- **影响事项**：课题成立与否、Q-002 重启门槛、是否切 B1/B2。
- **关闭判据**：小规模预试验在固定 VA 强度后，盲评者仍能稳定区分目标风格轴（κ ≥ 预登记阈值），或明确记录该轴与 arousal 不可分→记"不适用"并触发 B1 评估；预试验须基于 2D 资产。
- **来源**：2026-07-24 全组调研（visionary 坍缩风险、rigor #2 Critical、critic S4、builder MEAD confound）；D-003 收窄。
- **下次复核**：2D 版风格轴存在性预试验草案产出后、预试验执行时。
- **关联**：`Q-004`、`Q-002`；`_boss/briefs/2026-07-24-survey-2d-narrowing.md`；`_shared/stage_outputs/2026-07-24-survey-synthesis.md`；`D-003`。
- **解决记录**：未解决。D-003 后需重新评估 2D 下可验证性。
