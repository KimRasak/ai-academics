# 表达差分一致性：边界、混淆、威胁

> 从首轮形式化工作压缩。每次 Survey/Experiment 任务必读。

## 主张分解（核心）

课题"人物表情差分的一致性" = P1∧P2∧P4，三条**分别可证伪**：
- P1 可重复性（同条件低方差）
- P2 可区分性（风格可被留置盲评/分类器恢复）
- P4 解耦性（变风格不改身份/情绪）

P3 可控性是方法可用性主张，**不计入"一致性"**。多数论文报 P2 默认 P4——检索时须逐篇记录实际验证了哪几条。

## 最关键混淆

Arousal 混淆（Critical）：克制↔外放可能只是低↔高唤醒。未做"回归出 arousal 后残差风格仍可区分"前，任何"新风格轴"都是过度声称。身份漂移（Critical）：风格旋钮可能改下颌/眉骨而非表情肌。

## 评测循环警告

同模型生成+判别 ≠ 独立证据。须留置人类盲评 + 遮蔽面部裁剪。案例图不是"稳定"证据（Boss 在 Q-002 已定调）。

## Q-004 操作化判据（精简）

风格轴被接受 ⇔ 过风格卡+盲评可区分+情绪保持+身份保持+arousal 正交+维度独立。无现成"expression style" benchmark → 自建风格卡协议，举证负担加重。
