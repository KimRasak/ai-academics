# 第二轮调研小结：收窄到纯 2D 后，这个题目还值不值得做、风险在哪

> 这份小结假设您没有参与我们内部讨论，所有内部代号都用白话讲清楚。需要看研究者内部完整版，请读同目录 `2026-07-24-survey-2d-narrowing.md`。

## 先交代课题是什么

您之前定的课题（D-002）是**“人物表情差分的一致性”**，通俗讲：

> 同一个角色、同一种情绪下，脸部表达风格不同——比如同一张脸、都是“高兴”，一张是**克制地笑**、一张是**放声大笑**。这种“只变风格、不变身份和情绪”的差异，能不能被稳定地控制和测量？

您还定了两条范围（D-003）：**只看 2D 图像、不看 3D**；**只看近 2–3 年（2024–2026）AI 顶会论文**；并且**先不跑实验，先把问题找对**。

本轮就是在这些约束下，重新盘点“这个题目还有没有人做过、还值不值得做”，并报告新发现的风险。

## 一句话结论

剔除 3D 之后，这个题目的**研究空白**（指还没人做、因此值得做的领域）**从“没人做出方法”收窄为“没人做出评测标准”**——近 2–3 年 2D 人脸表情编辑（LivePortrait / EMO / IP-Adapter 这类“能控制表情且保住身份”的方法）已经把方法层占满了；但**“变风格的同时能不能同时保住身份和情绪”这件事，至今没有任何工作独立检验过**。因此团队建议：把主线从“再做一个生成/编辑方法”转向“先做判别和度量（先证明这是个值得做的好问题），生成留到后面”。同时发现一个新风险：纯 2D 下，实验所需的配对图片全是自己造的，而造的过程本身就偷偷塞进了课题要证的命题。

## 本次范围与证据边界

本轮是文献调研合成，**不是实验报告**。团队没跑实验、没复现、没下载任何资产。

- **可作事实陈述**：您已拍板“纯 2D、近 2–3 年顶会、表情差分”；3D 方向已剔除；检索标准已加两条硬约束（仅 2D / 近 2–3 年顶会正式录用）；表情差分的数学定义已在 2D 下重写；2D 配对数据的四个来源已审计。
- **仍是假设/判断（不应表述为定论）**：
  - “方法层已被占满、只剩评测层还空着”——本轮没拿到可核验论文引用，判断依赖问题内在逻辑 + 从 arxiv 抓到的预印本线索（FED-Bench / PixelSmile / RegGAN 等，**是否正式发表均未核实**）。
  - “‘变风格保身份情绪’从未被独立检验”是基于 arxiv 摘要印象的战略判断，非系统检索结论。
  - arxiv 预印本是否纯 2D、归属哪类，均待逐篇核实。

## 进展（3）

### 1. 研究空白重新盘点：从“方法空白”收窄为“评测空白”

剔除 3D 后，2D 人脸表情编辑赛道比 3D 更拥挤（MagicFace / InstaFace / RigFace / Face2Diffusion / DiffusionRig / LivePortrait / EMO / IP-Adapter 等 2024–2026 密集涌现）。但它们全在解决“能不能控制表情、能不能保身份”这类问题，**没有一家系统检验过下面这件事**：

> **只改表达风格，身份和目标情绪都不变**——团队内部把这条性质叫“解耦性”。

最接近的评测资源 FED-Bench（747 组数据，评 18 个编辑模型的“指令符合度/保真度/身份保持”）和 FFE-Bench，也都落在“编辑指令 / 表情强度”框架里，没触及“同一身份 × 同一情绪 × 只变风格”这种配对，也没人造“风格一致性”的度量标准。

**结论**：课题形态应从“又一个编辑方法”转向“风格差分一致性度量 + 受控配对协议 + 风格轴与情绪强度解耦检验”。

### 2. 表情差分的数学定义在 2D 下出了新问题

研究里有两个核心概念，白话讲：

- **“测表情的尺子”**：我们用一个表情特征空间来度量表情（原本用 3D 人脸模型，表情维度和身份/姿态维度在参数定义上就是分开的，尺子天然只测表情）。
- **“表达差分”**：固定住身份/情绪/姿态/服饰/背景都不变，只改风格，两张图在尺子上量出的差值。

换成 2D 之后，尺子改成“动作单元向量 / 2D 嵌入”，**身份/姿态/背景的信号都可能漏进尺子里，尺子不再天然干净**。于是用这把可能被污染的尺子，去检验“变风格不影响身份情绪”，会陷入“自己证自己”的循环。

**补救**：必须先用独立方法证明尺子干净（“变身份但差值方向不变”测试 + 两把尺子交叉验证），才能开始检验解耦性。检索标准也已加两条硬约束（仅 2D / 2024–2026 顶会正式录用，预印本不据以关闭空白）。

### 3. 实验配对数据全是自己造的，且造法自带污染——这是最隐蔽的新风险

课题需要的图片对（同角色、同情绪、只变风格）**自然界不存在**，必须自己造。而每种造法都自带一个隐含假设，举例：

- **造法 A（用现成编辑模型生成）**：隐含假设是“编辑模型真的能只改风格、保住身份和情绪”。但课题要证的恰恰就是这件事——你用一个假定它成立的模型去造数据，再用这数据去证明它成立，**等于自己证自己**。
- **造法 B（让人标注）**：隐含假设是“标注者真的能区分‘风格’和‘情绪强度’”。但如果标注者其实分不清，造出来的数据就已经被污染了。

四个造法按风险从高到低：编辑生成（循环论证，最危险）> 自标注 ≈ 2D 合成 > 已有编辑数据集（姿态协变消不掉）。

据此团队建议：把“**先判别后生成**”从替代方案**上调为 2D 首选主线**，“缩到动作单元级别”设为兜底——判别路径能绕开上述全部污染，且契合您“先找好问题、暂缓实验”。

## 需要您拍板的三件事

### 1. 首轮主线：转向“先判别/度量，后生成”还是仍含“生成控制”？

2D 下方法层很可能已被占满，生成路径又受上面说的“自己证自己”污染，在调研阶段没法干净论证。

- **(a) 先判别后生成**：先证明“风格差分能被稳定识别和度量”是个好问题，生成控制降为后续。critic 强烈推荐，契合您“先找好问题”。
- **(b) 仍保持“可控+识别+一致”三任务并进**：主线原貌，但 2D 下生成主张风险显著高于 3D 设定。

**团队推荐 (a)**。

- **为何现在确认**：范围决定检索重点、自建数据集规模和后续实验重启门槛；2D 下越晚改，污染返工成本越高。
- **确认后影响**：选 (a) 则首轮不碰生成器，主线为“差分可识别性基准 + 一致性指标组 + 受控配对协议”；选 (b) 则需在重启实验时同步准备生成实验并接受污染风险。

### 2. 配对数据怎么造才可信：要不要强制“两条独立造法、结果一致才采信”？

任何单一造法都有上面说的污染风险，单看一种造法的数据，没法知道结论是真发现还是造法带进来的。

- **(a) 强制要求**：配对数据必须同时用 ≥2 条互相独立的造法（比如“编辑模型生成”+“人工标注”各造一份），**只有两条造法得出的结论一致时才采信**；且数据清单里每对图片都标明“是哪个编辑模型/哪个标注协议造的”，方便事后审计。劣势：工作量翻倍，且两条造法可能暗地里共享同一个错误假设。
- **(b) 只用一条造法，事后多跑几个验证器交叉检查**：成本低，但没法对冲“造的当时”就埋下的污染。

**团队推荐 (a)**，至少在关键预试验阶段强制用。

- **为何现在确认**：决定数据集清单长什么样、预试验工作量多大，也直接影响后面“数据可公开审计”的承诺能不能兑现。
- **确认后影响**：选 (a)，数据清单里给每对图片标注“由谁造的”，预试验必须跨 ≥2 条造法；选 (b)，接受单造法的局限并在论文里明确写清证据边界。

### 3. 要不要给关键预试验设“硬门槛”，过不了就切兜底方案？

> 背景：有个关键预试验要验证“风格轴和情绪强度能不能分开”。2D 下这件事更难，容易混在一起。如果没分开就贸然进实验，事后发现混了，全部返工。

- **(a) 设为硬门槛 + 兜底**：主实验重启前，必须先通过“2D 版风格轴存在性预试验”（≥2 个不同的情绪强度回归器结论一致 + ≥2 条独立配对造法 + 预先登记一致性阈值并报置信区间 + 强制遮蔽非面部区域检查）；任一条造法跌破阈值，就切兜底方案（缩到动作单元级别）。rigor/critic/builder 一致推荐，2D 下触发概率高于 3D。
- **(b) 不设门槛，直接进入生成实验**：不推荐，混了就全部返工。

**团队推荐 (a)**。

- **为何现在确认**：若不前置，团队可能在风格轴尚未证成立时进入实验，事后发现与情绪强度不可分则全部返工；2D 下该风险更高。
- **确认后影响**：选 (a) 则主实验在预试验通过前不重启，预试验失败则切兜底；选 (b) 则接受坍缩返工风险。

## 主要风险

**数据构造循环性**——剔除 3D 后，2D 下“同一角色、同一情绪、仅变表达风格”的配对数据没有任何自然来源，全部由编辑模型/标注者/合成管线构造，而构造过程的隐含假设（编辑模型保身份、标注者能区分风格、提示词只改表情）正是课题要证的命题。这使得“身份保持”和“风格差分”的测量沦为“对构造器先验的测量”，且与“风格轴和情绪强度混在一起”（2D 下更难排除）叠加。这是 2D 专属、最隐蔽的失败机制，也是团队把“先判别后生成”上调为首选、把遮蔽检查升为强制的直接原因。
