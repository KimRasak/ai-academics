## A. 2D 配对数据瓶颈（Q-006）——四路径失败机制

共享前提：3D 渲染曾提供"固定 θ=(I,E,P,C,B)、只切表情通道"的可控实例化；剔除后 2D 没有任何"自然"的配对来源，所有路径都是**人为构造配对**，构造过程本身即引入混淆。

### 路径 1：2D 合成管线（用 2D 渲染器/StableDiffusion 出成对图）
- 失败机制 R1a：2D 渲染器没有"表情通道"这一正交控制量。改表情必然走语义提示词或 AU 条件，而语义提示词同时牵动年龄/性别/风格的视觉先验 → θ 在像素层不固定，F1（身份纠缠）在 2D 下更严重。
- R1b：用 SDXL/FLUX + ControlNet 出成对图时，"风格切换"很可能被模型实现为整体画风/光照/色温切换（背景泄漏、风格被强度偷换 S4）。
- 危险等级：高。

### 路径 2：已有身份保持表情编辑数据集（如 CelebV-HQ/VFHQ 衍生的表情编辑对）
- R2a：真实人脸 → 许可几乎全不可再发布（首轮 F5 不变）；且真实人脸没有"同一角色同情绪仅变风格"的标注，需自标注。
- R2b：真实视频里"同一人不同表情"伴随姿态/光照/年龄漂移，姿态协变在 2D 下**无法用 3DMM 投影消除**（3D 被剔除）→ 姿态协变成为不可控混淆。
- 危险等级：中高。

### 路径 3：自标注（在已有图集上让人工标"风格"）
- R3a：标注者先验偏置（S3）——"克制/外放"在真实人脸图上极易坍缩为"低/高 arousal"，即 S4 直接命中。κ 难超阈值。
- R3b：无锚点强制选择 → 标注者把"表情夸张度"当风格，arousal 混淆在标注阶段就注入，下游所有度量都被污染。
- 危险等级：高（且隐蔽，因为"有人工标注"显得可信）。

### 路径 4：diffusion 编辑生成（用编辑模型把一张脸改成另一风格）
- R4a（**2D 专属新捷径，最危险**）：编辑模型 identity leakage。当前主流 2D 表情编辑模型（LivePortrait/EMO/IP-Adapter 类）本身就被批评身份漂移；用它造配对数据 = 用一个未验证 P4 的模型去定义 P4，循环论证。测出的"身份保持"是编辑模型的上限，不是课题结论。
- R4b：编辑模型把"风格"实现为 AU 幅度缩放 → 风格轴坍缩回 arousal（Q-005 命门）。
- 危险等级：最高。因为它同时是数据来源、又是被审对象，循环性最强。

### 路径危险排序
路径4 > 路径3 ≈ 路径1 > 路径2。
共同根因：2D 下"配对"是构造出来的，构造过程的隐含假设（编辑模型保身份、标注者能区分风格、提示词只改表情）正是课题要证的命题。

## B. 3D 剔除后风险重评

### B.1 可控性受损（确认）
3DMM/FLAME 表情通道是唯一"先验上正交于身份/姿态"的 φ 实例化。剔除后，2D 的 φ（AU 估计器 / 人脸嵌入 / VA 回归器）全部是从真实人脸学到的，对虚拟角色分布偏移；且 2D φ 之间互不蕴含。"差分 Δ 在 φ 中定义"这一前提在 2D 下变得更弱：Δ 依赖 φ 的选择，φ 选择不同会给出不同结论 → F2（一致性不可证伪）在 2D 下加重。

### B.2 可证伪性受损（部分）
3D 路径下，"固定 θ 只切表情通道"是可机器验证的（通道系数直接读）。2D 路径下，"只变 S、不变 I/E/P/C/B"是一个**经验声明**，需要事后用 ArcFace/FER/VA 回归器验证，而这些验证器本身分布偏移 → 验证链条变长、每环都有捷径。结论：可证伪性下降一档，但未归零（仍可用多验证器一致性 + 盲评交叉）。

### B.3 新增混淆（2D 专属）
- 姿态协变：3D 可固定姿态参数，2D 不能（头部俯仰/偏航随表情变化）。
- 背景泄漏：3D 渲染背景纯色，2D 真实/生成图背景含语义信息，被风格信号搭便车。
- 光照协变：3D 光照可控，2D 表情变化常伴随光照反射变化（高光/阴影）。
- 分辨率/画质协变：编辑模型输出画质下降本身被当风格差异。

### B.4 pre-mortem 5 条在 2D 下的更新
- F1（身份纠缠）：严重度 3D下=高 → 2D下=极高（无正交通道兜底）。
- F2（一致性不可证伪）：2D 下加重（φ 选择自由度更大）。
- F3（无 benchmark）：不变（仍无配对差分 benchmark）。
- F4（trade-off）：不变。
- F5（合规）：2D 真实人脸仍不可再发布，但 2D 合成数据许可比 3D 资产更易处理 → 略缓解。
- **新增 F6（数据构造循环性）**：2D 配对数据由编辑模型/标注者构造，构造过程蕴含课题结论 → 测量即测量构造器的先验。这是 2D 专属、最隐蔽。
- **新增 F7（姿态/背景/光照协变）**：3D 剔除后失去对这些因子的参数化控制，成为不可控混淆。

## C. 6 条评测捷径在 2D 下的变化

| 捷径 | 3D 下严重度 | 2D 下严重度 | 变化原因 |
|---|---|---|---|
| S1 identity↔expression trade-off | 高 | 高 | 不变 |
| S2 FER 分类器循环性 | 高 | 极高 | 2D φ 全是真实人脸训练的，对虚拟脸偏移更大 |
| S3 人类盲评协议缺陷 | 中 | 高 | "风格"在 2D 真实脸上更易被 arousal 偷换 |
| S4 风格被强度偷换 | 高（头号） | 极高（仍是头号） | 2D 没有强度参数可控，更难排除 |
| S5 随机性伪装成风格 | 中 | 中 | 不变 |
| S6 cherry-picking | 中 | 中 | 不变 |

### 2D 专属新捷径
- **S7 编辑模型 identity leakage（对应 R4a）**：用编辑模型造配对数据时，身份保持度上限=编辑模型能力，课题测到的 P4 是编辑模型的 P4，不是"风格切换"的 P4。验证：换多个不同编辑模型造配对，看结论稳定性。
- **S8 φ-选择自由度（对应 B.1）**：差分 Δ 依赖 φ，不同 φ（AU vs 嵌入 vs VA）给出不同一致性结论，研究者可挑 φ。验证：主表必须报 ≥2 类异质 φ 的结果。
- **S9 姿态/背景/光照搭便车**：风格信号由非面部区域承载。验证：遮蔽检查（masking check）在 2D 下从"建议"升级为"强制"。

## D. 2D 白色空间是否仍真实

### 判断（高不确定性）
- 内在逻辑：3D 剔除不改变"无公开配对差分 benchmark"这一事实（F3 仍成立），所以白色空间在"benchmark/指标"层仍可能真实。
- 但"方法"层白色空间很可能已被近 2-3 年顶会占据：身份保持表情编辑（LivePortrait/EMO/IP-Adapter 类）本身就是"2D 上控制表情同时保身份"的工作，P2/P4 在这些工作里被隐式报告。课题若仍主张"可控+一致"，审稿人第一反应="这和 LivePortrait 有什么本质区别"。
- 最可能被占据的子空间：(1) 身份保持的表情强度控制；(2) AU/3DMM 条件的表情编辑。**未被占据的窄缝**："风格轴与 arousal 解耦后残差风格的一致性"——这正是 Q-005，且在 2D 下更难证。
- 不确定性声明：WebSearch 本轮未返回可核验论文引用，上述"被占据"是基于问题逻辑的推断，**不应作为定论**。rigor+builder 须按更新后检索标准逐篇核实 2024-2026 顶会。

### B1/B2 在 2D 下是否更优
- B1（AU 级收窄）：2D 下**更优**。AU 有 OpenFace/MediaPipe 估计器，差分有数学定义，且 AU 与身份的解耦在 2D 下仍比"风格"干净。代价：AU 估计器对虚拟脸偏移（首轮已记），但这是可量化的噪声，比"风格"的不可证伪性好。
- B2（先判别后生成）：2D 下**显著更优**。判别任务只需"人/模型能否区分风格"，不需要可控生成，绕开 2D 配对数据瓶颈（R1-R4）和编辑模型循环性（R4a/S7）。与 Boss"暂缓实验、先找好问题"高度契合。
- 建议：把 B2 从"替代方案"上调为"2D 下的首选主线候选"，主线生成降为后续。理由：2D 下生成路径的循环性（F6）使生成主张在 Survey 阶段无法干净论证，而判别路径可先用已有图集做。

## E. Q-005 在 2D 下的可验证性

- 3D 路径下，Q-005 预试验可"固定 arousal 通道系数、切风格通道"做正交性检验。2D 下 arousal 不是通道、是回归量输出，"固定 arousal"只能靠"回归后取残差"，而回归器本身分布偏移 → S2+S4 双重污染。
- 结论：Q-005 在 2D 下**显著更易被捷径污染**，预试验结论可信度下降一档。
- 加固建议：(1) 用 ≥2 个异质 arousal 回归器取一致性；(2) 配对数据必须跨 ≥2 条独立构造路径（如合成+自标注），结论一致才采信；(3) 预登记 κ 阈值并报 CI；(4) 若任一路径下残差风格 κ 跌破阈值，即触发 B1 评估——2D 下该触发概率比 3D 下更高，应预设 B1 为兜底。
