# Survey 检索纳入/排除标准 + 表达差分一致性主张边界

> rigor 产出。作为本轮各角色文献检索的纳入/排除门槛，以及"人物表情差分一致性"主张的形式化边界。
> 关联：D-002、D-003、Q-001（已关闭）、Q-004、Q-005。术语定义见 `_shared/glossary.md`。
>
> **2026-07-24 D-003 修订**：新增两条硬约束——(a) 仅 2D 图像；(b) 近 2–3 年（约 2024–2026）AI 顶会。原"3DMM 表情系数"作为 φ 实例化路径**失效**，φ 限定到 2D 表征（AU 向量 / 限定到表情通道的 2D 嵌入）。形式化见 §1，检索标准见 §2/§3。

## 1. 主张的形式化边界

设生成器 $G$，固定条件 $\theta=(I,E,P,C,B)$（身份/情绪/姿态/服饰/背景），风格 $s\in\mathcal S$（如 {restrained, outward}），采样噪声 $\xi$，输出 $x=G(\theta,s,\xi)$。表情特征空间 $\phi$（**D-003 后限定到 2D 表征**：AU 向量 / 限定到表情通道的 2D 嵌入；3DMM/3D 表情系数路径已剔除）。表达差分：

$$\Delta_{s_1,s_2}=\phi(G(\theta,s_1,\xi))-\phi(G(\theta,s_2,\xi))$$

**课题主张**："同一角色稳定呈现多种可区分的脸部表达" = P1 ∧ P2 ∧ P4（见 glossary `consistency`）。各子命题**分别可证伪，不得合并**：

- P1 可重复性：$\mathrm{Var}_\xi[\phi(G(\theta,s,\xi))]\le\sigma^2_{repeat}$
- P2 可区分性：$s_1\ne s_2$ 时留置盲评/分类器恢复 $s$ 高于 chance+δ（含 CI）
- P4 解耦性：变 $S$ 不改身份（$\ge\tau_{id}$）且不改情绪（分类器稳定 + VA 漂移 ≤ 阈值）

**排除的主张**（D-002/Q-001）：从图像还原/生成真实人格；MBTI/Big Five 等心理特质真值。

**边界警告**：P3（可控性）是方法可用性主张，不计入"一致性"本身。多数论文报告 P2 并默认 P4——本轮检索须记录每篇论文实际验证了哪几条。

## 2. 纳入标准（论文须**同时**满足 §2.0 两条硬约束，且满足下列任一）

### 2.0 硬约束（D-003，一票否决）

- **C1 仅 2D 图像**：方法主体在 2D 图像域运作。涉及 3DMM/FLAME/VRoid/Ready Player Me/BEAT/FaceWarehouse 等 3D 资产、3D 表情捕获、3D 可控渲染作为方法核心的论文一律排除（仅用 3DMM 作**中间监督信号**但最终输出/评测在 2D 的，须在笔记中显式标注并降权，不算作方向候选）。
- **C2 近 2–3 年顶会**：发表于 CVPR/ICCV/ECCV/NeurIPS/ICML/ICLR/AAAI/SIGGRAPH（及 SIGGRAPH Asia/TOG）2024–2026 年。arXiv preprint 可作为线索，但**不计入白色空间占据判定**——须以正式顶会录用为准；preprint 须标注"未录用"且不据其关闭白色空间。

### 2.1 主题纳入（满足任一）

1. 可控面部表情生成/编辑，含显式风格或属性轴（非仅情绪类别）。
2. 身份保持的人脸生成/编辑（风格/身份解耦）。
3. 把表情从身份/姿态中分离的表征学习。
4. 表情一致性、身份保持、表情多样性的评测指标或 benchmark。
5. 基于 AU/FACS 的表情控制或分析，且与风格轴相关。
6. 个性化/角色化的表情生成（character/persona-specific expression）。

## 3. 排除标准

1. 纯情绪识别/分类、无生成或编辑成分（指标可单独借用，但不作方向候选）。
2. 从人脸推断人格/心理特质（D-002/Q-001 排除）。
3. 纯 face swap / reenactment，无表情风格轴。
4. 通用 text-to-image，无面部表情控制。
5. 非面部情绪（仅身体/语音）。
6. **3D 话题**（D-003）：3D 资产/3D 捕获/3D 渲染主导的方法。
7. **超出时间窗**（D-003）：2024 年前发表的论文（经典基线如 StyleCLIP、InterFaceGAN 等可作为背景引用，但不计入白色空间占据核实）。

## 4. 关键混淆变量（检索时须记录论文是否控制）

| 混淆 | 如何伪装为"表达差分" | 控制手段 | 优先级 |
|---|---|---|---|
| Arousal/强度 | 克制↔外放 ≈ 低↔高唤醒 | 回归出 arousal 后残差风格可区分 | Critical |
| 身份漂移 | 风格旋钮改下颌/眉骨 | 身份保持度量（人脸识别余弦） | Critical |
| 姿态协变 | 外放愤怒⇒头前倾 | 固定姿态；姿态回归 | Major |
| 服饰/背景泄漏 | 风格 prompt 连带改背景 | 遮蔽检查 | Major |
| 情绪漂移 | 外放愤怒⇒rage/hate | 情绪分类器稳定性 + VA 漂移阈值 | Major |
| AU 可归约性 | 风格=AU 组合 | 是否在 AU 之外有独立结构 | Minor（待定义） |
| 评测循环 | 同模型生成+判别 | 留置人类盲评（遮蔽面部裁剪） | Critical |

## 5. Q-004 表达风格最小可验证操作化草案

候选轴 $S$（克制/外放、眉眼/嘴部主导、回避/直视）被"操作化接受"当且仅当通过预注册小测：

1. **风格卡**：标签集、定义性面部线索（AU 模式，如克制愤怒=低 AU4+AU7，外放=高 AU4+AU23+AU24）、正/负样例。
2. **盲评可区分**：≥N 名盲评者对遮蔽面部裁剪对标注风格；准确率 > chance+δ，Fleiss κ ≥ κ₀。N/δ/κ₀ 待 builder+rigor 定。
3. **情绪保持**：独立情绪分类器对两种风格输出同一 $E$（容差 ε）；预测 VA 漂移 ≤ 阈值。
4. **身份保持**：人脸识别余弦 ≥ τ_id。
5. **Arousal 正交**：回归出预测 arousal 后，残差风格可区分性仍高于 chance。
6. **维度独立**：三个候选轴两两不冗余（残差判别不塌缩）。

### 依赖的 benchmark/指标（仅线索，不确定标"待 builder 核实"）

- **AffectNet**（连续 VA 标注）— arousal/valence 回归器 [待 builder 核实许可与可用性]
- **BP4D+ / DISFA**（AU 真值）— AU 级风格线索验证 [待 builder 核实]
- **ArcFace / 人脸识别模型** — 身份保持 [待 builder 核实模型与许可]
- **情绪分类器**（AffectNet/RAF-DB 训练）— 情绪保持 [待 builder 核实]
- **表达风格 benchmark：无现成** — 团队需自建小规模风格卡标注协议。
  > rigor 标注的缺口：该构造是新的，无外部 benchmark 可做独立验证，举证负担加重；Q-004 关闭判据要求小规模预试验证明遮蔽后仍可识别或明确记录不适用。

### 7.2 占据判定门槛

一篇论文"占据白色空间"当且仅当**同时**：
1. 在 2D 图像域（满足 C1）；
2. 顶会正式录用 2024–2026（满足 C2）；
3. 至少验证 P2 且 P4（身份保持+情绪保持）有独立证据（非默认）；
4. 显式检验了风格轴与 arousal 的正交性（或等价地证明风格轴不可归约为强度）。

只满足 1–3 而缺 4：记为"部分占据，arousal 混淆未排除"，白色空间在该维度仍开放。
preprint 不据以关闭白色空间，仅记为"潜在威胁，待录用确认"。

## 8. φ 在 2D 下的边界与补救（D-003 后新增）

3DMM/3D 表情系数路径失效后，φ 限定为：
- **φ_AU**：FACS AU 向量（需 AU 检测器，如 OpenFace/ME-GraphAU 类）。优点：可解释、与 arousal 正交检验天然兼容；缺点：AU 检测器在生成图上的域偏移未量化，且 AU 离散化可能丢失微表情。
- **φ_2Demb**：限定到表情通道的 2D 人脸嵌入（如表情分类器倒数第二层）。优点：连续；缺点：嵌入可能编码身份/姿态，须做正交化剥离。

**Δ 的可控性损失**：3D 路径曾提供"渲染不变"的差分（同一 θ 下仅变表情系数）；2D 下 φ 作用于渲染后图像，姿态/光照/头发进入 φ 的风险上升。补救：
1. 评测时固定 $P$、回归残差化掉姿态；
2. φ_2Demb 须通过"变身份保 Δ"测试：$\Delta$ 在不同 $I$ 下方向一致才算表情通道；
3. 双 φ 交叉验证（φ_AU 与 φ_2Demb 给出一致排序）以对抗单一 φ 的偏置。

P1/P2/P4 的可证伪性不变，但**度量前提加重**：须先证明 φ 本身不编码身份/姿态，否则 P4 的"身份保持"度量与 φ 污染耦合，出现循环。
