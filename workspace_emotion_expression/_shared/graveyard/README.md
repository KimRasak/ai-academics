# 墓地：被否决的方案

> 记录"什么不 work"和"为什么被否决"。科研里失败路径和成功路径同样有价值，也对应研究演化树的 `fork` 分支。
> 每条必含三件：否决判据 + 当时证据 + 复活条件。半年后无法审计的否决 = 假资产。

格式：

```markdown
## [方案名]（否决日期）
- **提出者**：
- **原意**：
- **否决原因**：
- **否决者/依据**：
- **可复用部分**：（如果有）
- **复活条件**：（在什么条件下可重新评估——必须是可观测的触发事件，不得写"永久封印"）
```

---

## AI-Scientist（2026-07-27 记入）

- **提出者**：critic 据公开信息整理（Lu et al. 2024, Sakana AI）
- **原意**：端到端自动化科研闭环：生成想法 → 实验 → 写作 → 评审，目标产出顶会级论文。
- **否决原因**：阶段错配。AI-Scientist 是**实验/闭环阶段工具**——它需要一个已成立的假设、可跑的实验环境与可量化的验证信号才能启动。Survey 阶段（当前）既无假设（Q-005 风格轴存在性未验）、也无 baseline 清单（D-002 暂缓实验）、更无可跑环境。在调研期投入它，等于在没有问题的真空中跑闭环，产出会是"看起来像论文的幻觉"。
- **否决者/依据**：critic / D-002 "暂缓实验" + 工具"真跑通"三档（L1 假跑通、L2 真实负载、L3 对抗探针）均无对象可验。
- **可复用部分**：其"模拟审稿人"模块在 Writing/Review 阶段可作为 weakness 预测的对照之一（不作为唯一源，须与真人审稿模式交叉）。
- **复活条件**：以下三条**全部**满足时可重新评估为实验闭环候选：(1) Boss 放行实验（Q-002 重启）；(2) 已有 ≥1 条写明样本/对照/盲评/阈值的预试验计划；(3) baseline 清单与可跑环境已就位。**仅满足 (1) 不够**——没有预试验计划的闭环跑不出可审计结论。

## RD-Agent（2026-07-27 记入）

- **提出者**：critic 据公开信息整理（Tencent，data + solution 双 agent 闭环）
- **原意**：数据-方案协同演化：一个 agent 提数据策略、一个提解决方案，迭代提升指标。
- **否决原因**：阶段错配 + 依赖错配。RD-Agent 的演化依赖**已存在的可量化指标**作为反馈信号。当前课题的核心指标"风格差分一致性"尚不存在（F2"一致性不可证伪"未解、F3 无对应 benchmark），且 Q-005 解耦性命题未验。在没有可量化的成功信号下跑 RD-Agent，演化方向会被代理的内部 reward 劫持，产出不可解释。
- **否决者/依据**：critic / F2+F3 未解 + D-002 暂缓实验。
- **可复用部分**：其"data agent 提数据策略"子模块在 Q-006 配对数据构建阶段可参考（用于自动探索 2D 合成管线的参数空间），但须由 builder 主导、critic 监督防捷径，不作为自动闭环。
- **复活条件**：以下三条**全部**满足：(1) 风格差分一致性指标已定义并通过 F2 可证伪审计（≥2 异质度量器交叉）；(2) Q-005 预试验已通过（风格轴与 arousal 解耦成立）；(3) Boss 放行实验。任一条件失效则继续搁置。

## karpathy/autoresearch（2026-07-27 记入）

- **提出者**：critic 据公开信息整理（Karpathy 演化树概念，根目录 `autoresearch_tree.md`）
- **原意**：把科研建模为"假设树"，节点是命题、边是证据/反驳，自动扩展与剪枝。
- **否决原因**：抽象层级错配。autoresearch 是**概念框架**，不是可执行工具；它需要"已能产出可验证假设"的下游层（实验、检索）才有意义。当前 Survey 阶段连"先判别后生成 vs 仍含生成"主线都未由 Boss 拍板，假设树形结构本身就在浮动——此时建树等于把树画在沙上。演化树概念已被团队用作**叙事工具**（voice 的方法演进对比表），这层使用是安全的；但作为"自动扩展/剪枝的闭环"投入则否决。
- **否决者/依据**：critic / 主线未定（Boss 3 项待拍板未回）+ D-002 暂缓实验。
- **可复用部分**：演化树作为**叙事结构**（voice 已在用）安全；"边带证据等级"的标注方式可在 Writing 阶段作为论文 related work 的组织骨架。
- **复活条件**：以下两条**同时**满足：(1) Boss 已拍板 3 项待确认事项（主线 / 配对造法 / 预试验门槛），假设树根节点固定；(2) 至少进入 Ideation 阶段、有 ≥2 个可比较的方案节点可画边。在此之前只作叙事用、不作闭环用。

---

> critic 注：以上三条均因**阶段错配**而非工具本身缺陷否决。这是"复活条件"必须写清触发事件、不得写"永久封印"的核心理由——阶段会推进，工具会被重新评估。半年后（2027-01）若仍无人审计这些条目，记为假资产并强制重评。
